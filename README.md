# A-library-book-reservation-system

ShelfReserve — a responsive library book reservation UI built with plain HTML, CSS, and JavaScript for CSE346.3 Lab Assignment.

## Pages

- `index.html` — landing page (navbar, hero, feature cards, footer)
- `reserve.html` — reservation form with client-side validation

## How to run

Open `index.html` in a browser, or serve the folder with any static server.
